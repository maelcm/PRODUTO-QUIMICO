═══════════════════════════════════════════════════════════════
  NAVEGAR PARA O DIRETÓRIO CORRETO
═══════════════════════════════════════════════════════════════

No PowerShell:
   cd "C:\Users\Info\PRODUTO QUIMICO\SISTEMA_WEB_NFE"

OU simplesmente (se já estiver na raiz):
   cd SISTEMA_WEB_NFE

═══════════════════════════════════════════════════════════════
  COMANDOS PRINCIPAIS
═══════════════════════════════════════════════════════════════

1. Verificar Setup:
   .\VERIFICAR_SETUP.bat

2. Instalar Dependências:
   .\INSTALAR_TUDO.bat

3. Executar Migrações do Banco:
   .\EXECUTAR_MIGRACOES.bat
   
   OU manualmente:
   cd server
   npm run db:push
   cd ..

4. Iniciar Sistema:
   npm run dev
   
   OU:
   .\INICIAR_SISTEMA.bat
