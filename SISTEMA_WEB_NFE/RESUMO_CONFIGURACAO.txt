  PRÓXIMOS PASSOS OBRIGATÓRIOS
═══════════════════════════════════════════════════════════════

1. CONFIGURAR DATABASE_URL (se necessário)
   ────────────────────────────────────────────────────────────
   O arquivo .env está configurado com valores padrão:
   DATABASE_URL=mysql://root:@localhost:3306/nfe_system
   
   Se seu MySQL tem senha, edite o arquivo .env:
   
   Abra: SISTEMA_WEB_NFE\.env
   
   Altere para:
   DATABASE_URL=mysql://root:SUA_SENHA@localhost:3306/nfe_system
   
   Ou execute: CONFIGURAR_ENV.bat

2. CRIAR BANCO DE DADOS
   ────────────────────────────────────────────────────────────
   Execute um dos seguintes:
   
   Opção A: Script automático
   > CRIAR_BANCO.bat
   
   Opção B: Manualmente no MySQL
   CREATE DATABASE nfe_system;

3. EXECUTAR MIGRAÇÕES
   ────────────────────────────────────────────────────────────
   Execute:
   > EXECUTAR_MIGRACOES.bat
   
   Isso criará todas as tabelas no banco de dados.

4. INICIAR O SISTEMA
   ────────────────────────────────────────────────────────────
   Execute:
   > INICIAR_SISTEMA.bat
   
   Ou use o atalho na área de trabalho: "Sistema Web NF-e"

═══════════════════════════════════════════════════════════════
  SCRIPTS DISPONÍVEIS
═══════════════════════════════════════════════════════════════

CONFIGURAR_ENV.bat           - Configura o .env interativamente
CRIAR_BANCO.bat              - Cria o banco MySQL
EXECUTAR_MIGRACOES.bat       - Executa migrações do Drizzle
INICIAR_SISTEMA.bat          - Inicia o sistema (backend + frontend)
SETUP_COMPLETO_AUTOMATICO.bat - Faz tudo automaticamente
EXECUTAR_CONFIGURACAO_COMPLETA.bat - Configuração completa

═══════════════════════════════════════════════════════════════
  PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════

❌ "Erro ao conectar ao banco"
   → Verifique se MySQL está rodando
   → Verifique DATABASE_URL no .env
   → Verifique se o banco 'nfe_system' existe

❌ "Arquivo .env não encontrado"
   → Execute: EXECUTAR_CONFIGURACAO_COMPLETA.bat

❌ "Porta já em uso"
   → Feche outras aplicações nas portas 3001 ou 5173
